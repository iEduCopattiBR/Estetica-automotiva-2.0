# Schmitt Detailer

## Gerar o APK (GitHub Actions)
Suba os arquivos no GitHub e rode o workflow "Build APK". O APK sai em Actions > execução > Artifacts.
Se já tiver versão antiga instalada, desinstale antes na primeira vez.
