# Schmitt Detailer – como gerar o APK (pelo celular)

1. No GitHub (app ou navegador), crie um repositório novo e suba TODOS os arquivos desta pasta
   (inclusive as pastas `.github`, `android` e `src`).
2. Abra a aba **Actions** > **Build APK** > **Run workflow** (ou ele roda sozinho ao enviar os arquivos).
3. Quando terminar (verde, ~5 min), abra a execução e baixe **SchmittDetailer-apk** em *Artifacts*.
4. Extraia o .zip baixado e instale o `app-release.apk`.

Se já tiver uma versão antiga instalada, DESINSTALE antes (a assinatura mudou).
